# Majestic Print redesign workspace

Open **Majestic Print Project Vault** as a folder/vault in Obsidian and start at **00 Start Here.md**. Ordinary Markdown and core Obsidian features; no community plugins required.

The supplied **BRAND GUIDELINES copy.pdf** is the identity and service-scope source of truth. The plan now uses **Print. Pack. Promote.**, its exact palette and named fonts, and all 12 service families. Font files/licences, master logo variants, rates and real photography remain pending.

Review files:

- `planning/wireframes/index.html` — start here: complete linked wireframe set, including product, About and commerce screens.

- `planning/sitemap.html` — full page tree with purpose and per-page section structures.
- `planning/homepage-wireframe.html` — responsive annotated homepage layout study.
- `planning/sitemap.json` — machine-readable proposed routes/page structures.

The homepage wireframe is a design-review artifact, not a functioning commerce site. Product checkout, uploads, payment integration and WordPress conversion are later stages.

Research and revision date: 5 October 2026 (Asia/Colombo). Current production: https://majesticprint.lk/

Open the saved HTML files in a browser to review them; no build step is required. The design notes can be hidden with the checkbox. Verification status and remaining runtime checks are in `90 Evidence/Planning Verification.md` inside the vault.
